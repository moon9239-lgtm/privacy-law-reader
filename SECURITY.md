# Security

Please report security issues responsibly.

Do not post tokens, personal data, private deployment details, or exploit instructions in public issues, discussions, pull requests, or comments.

Use GitHub private vulnerability reporting where available. If private reporting is not available, open a minimal public issue that says a security report is needed, without including sensitive details.

This public repository is intended to remain static and secret-free. Reports about accidentally committed credentials, private project IDs, unsafe links, or exposed personal data are in scope.
