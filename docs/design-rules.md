# 보-편 디자인 규칙

## 데스크톱 방문자 수 표시

데스크톱 헤더의 방문자 수 표시는 다음 형태로 고정한다.

`방문자수 | Total 숫자 · Today 숫자`

규칙:

- 헤더에 자연스럽게 붙는 작은 텍스트형 표시를 유지한다.
- 카드, pill, 테두리, 그림자, 배경색 칩으로 바꾸지 않는다.
- 방문자 아이콘을 데스크톱 표시 안에 다시 넣지 않는다.
- `Total`은 보조 텍스트 색상, `Today`는 현재의 강조 색상을 유지한다.
- 모바일은 화면 폭 제약 때문에 별도 compact 규칙을 사용할 수 있지만, 데스크톱 기본 규칙을 변경해서는 안 된다.
- 이 규칙을 바꿔야 한다면 먼저 이 문서와 `tests/public-contract.test.mjs`의 디자인 계약을 함께 갱신하고, 실제 데스크톱 화면을 확인한다.

이 규칙은 방문자 수 기능의 데이터/API 동작이 아니라, 보-편 헤더의 시각적 일관성을 보호하기 위한 규칙이다.
