# 보호법 편히보기

개인정보 보호법을 웹브라우저에서 읽기 쉽게 보여주는 정적 리더입니다. 서버, 로그인, 데이터베이스 없이 저장소 안의 조문 데이터와 공식 출처 목록을 화면에 펼쳐서 보여줍니다.

개발자가 아니어도 복제해서 열어 보고, 문서를 따라 테스트한 뒤, 다른 법령이나 공공문서 리더로 바꿔 볼 수 있게 구성했습니다.

## 바로 확인하는 명령

프로젝트 폴더에서 아래 세 가지를 실행해 보세요.

```powershell
npm.cmd test
```

```powershell
npm.cmd run build
```

```powershell
npx serve dist
```

마지막 명령은 빌드된 `dist` 폴더를 로컬 정적 서버로 여는 예시입니다. 다른 정적 서버 도구를 써도 됩니다.

## 의도적으로 제외한 것

- PDF 원본 파일 묶음
- 개인 Vercel 프로젝트 ID와 배포 URL
- 운영용 환경 변수, 토큰, 비밀값
- 비공개 분석, 관리자 API, 데이터베이스 연결
- 사용자를 추적하는 분석 확장

공식 문서는 링크로 안내하고, 저장소에는 공개 리더를 실행하는 데 필요한 파일만 남깁니다.

## 법률정보 한계

이 저장소의 법률 정보는 읽기 보조 도구입니다. 실제 업무, 사건, 신고, 계약, 분쟁에 적용하기 전에는 반드시 법령정보센터 등 공식 출처에서 현재 유효한 원문과 최신 개정 여부를 확인해야 합니다.
